Future Techies is a responsive and animation-rich landing page created entirely with HTML and CSS. The goal of this project is to demonstrate how modern web interfaces can be built without JavaScript by leveraging advanced CSS techniques.

The website includes:

Animated gradient background and floating effects

Interactive navbar with hover underline animation

Glow and gradient text effects

Ripple and floating call-to-action button

Glassmorphism feature cards with shine hover animation

Clean and minimal responsive layout

This project serves as a beginner-friendly frontend portfolio piece and a foundation for building a complete multi-page tech community website in the future.
